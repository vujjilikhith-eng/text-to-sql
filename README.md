# Ask Your Database: text-to-SQL app
https://text-to-sql-chvy38uy3rinfca5rkkdqk.streamlit.app/

Type a question in plain English and get the answer from your database as a table. No SQL needed.

Example: *"Which car model was rented the most?"* or *"Which rentals are overdue?"*

The app uses an AI model (Google Gemini) to write the SQL query, checks that it is read-only, runs it, and shows the result.

## Features

- Chat-style interface: type a question, press Enter
- Connect to a **demo database**, an uploaded **SQLite file**, **MySQL** or **PostgreSQL**
- Reads the table structure automatically, so it works with any database
- Shows the generated SQL (hidden by default) and lets you download the result as CSV
- If a query fails, the AI gets the error and tries once more

## How it stays safe

1. Only a single `SELECT` query is allowed. Words like `DROP`, `DELETE`, `UPDATE` and `INSERT` are blocked.
2. The database connection is read-only (SQLite read-only mode with an authorizer; read-only sessions for MySQL and PostgreSQL).
3. Queries stop after 5 seconds and return at most 500 rows.
4. The AI receives only table and column names and the question. The rows of your data are never sent to it.

For MySQL and PostgreSQL, connect with a read-only database user. The app shows the commands to create one.

## Demo data

The app works with any database. To let you try it right away, it includes a demo database (the "RentDrive" car rental company).

`rentdrive_sample.db` is a SQLite database for a made-up car rental company (branches, customers, vehicles, reservations, rentals, invoices, payments, damage reports). All data is generated by `build_sample_db.py`; there are no real customers.

## Run it locally

```bash
pip install -r requirements.txt
```

Get a free Gemini API key at [Google AI Studio](https://aistudio.google.com/api-keys), then set it:

```powershell
# Windows PowerShell
$env:GEMINI_API_KEY = Read-Host "Paste your key"
```

```bash
# macOS / Linux
export GEMINI_API_KEY="your-key"
```

Start the app:

```bash
python -m streamlit run app.py
```

Never put your API key in the code or commit it to GitHub.
